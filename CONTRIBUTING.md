# Contributor Guidelines

Thank you for contributing to this repository! The following types of contributions are welcome:

- Bug reports: please open a GitHub Issue.
- Bug fixes: If you are making a minor change, please open a GitHub pull request. If you are making major change, please open a GitHub issue for discussion first.
- Feature requests: Please open a GitHub issue for discussion.
- New features: Please open a GitHub issue for discussion.
- Feedback: Please open a GitHub issue for discussion, or submit your feedback to the feedback form.

## AI Policy

- Pull requests may **not** be submitted to this repository by autonomous AI agents. 
- Pull requests that have been generated using AI tool usage are permitted, under the following conditions:
  - AI tool usage **must** be disclosed in the commit message, either through a tag or a short description.
  - The description **should** include the name of the AI tool used.
  - The pull request **must** be submitted by a human author who is responsible for the content of the pull request.
